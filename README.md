# ⚽ Mini Football Tools (MFTools)

The ultimate toolkit for **Mini Football** players.

MFTools is a community-driven website that provides useful tools, player statistics, calculators, guides, and other helpful resources for the mobile game **Mini Football**.

> 🚧 This project is currently under development.

---

## ✨ Features

### 📊 Player Database
- Search every player
- View detailed player stats
- Filter by rarity, position, nationality, club and more
- Compare players

### 🔍 Scout Tools
- Scout timers
- Scout information
- Scout rewards
- Scout probability calculator *(planned)*

### 📈 Statistics
- Player rankings
- Best players by position
- Team value
- Collection progress

### 🧮 Tools
- Team Builder
- Upgrade calculator *(planned)*
- Resource calculator *(planned)*
- Pack value calculator *(planned)*

### 📚 Guides
- Beginner guides
- Advanced tips
- Best teams
- Meta recommendations

### 📰 News
- Game updates
- Events
- New players
- Patch notes
